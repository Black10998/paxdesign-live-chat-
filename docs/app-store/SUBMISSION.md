# App Store Submission Guide — v2.0.0

Official App Store release workflow for **PAXDesign Live Chat**.

## Prerequisites

- Apple Developer Program membership
- App Store Connect access with API key
- Signing certificate + provisioning profiles for `at.paxdesign.livechat`
- WordPress plugin **3.124.0** deployed to production

## Automated release pipeline

The repository includes CI workflows for the full release:

1. **WordPress deploy** — `.github/workflows/deploy-and-verify-3124.yml`
2. **App Store IPA build** — `.github/workflows/release-appstore.yml`
3. **TestFlight upload** — `.github/workflows/upload-testflight.yml`
4. **App Store submit** — `.github/workflows/app-store-submit.yml`

Trigger all release steps by pushing to `main` with updated trigger files, or run workflows manually via `workflow_dispatch`.

### Manual steps (local)

```bash
# 1. Generate screenshots
python3 scripts/appstore-connect/generate_screenshots.py

# 2. Build IPA (macOS + Xcode required)
cd paxdesign-booking/ios-live-chat
./scripts/build-appstore-ipa.sh

# 3. Upload to App Store Connect
./scripts/appstore-connect/upload-ipa.sh build/AppStore/export/PAXDesignLiveChat-AppStore.ipa

# 4. Upload screenshots + metadata + submit for review
python3 scripts/appstore-connect/upload_app_store_screenshots.py
python3 scripts/appstore-connect/submit_app_store_review.py
```
