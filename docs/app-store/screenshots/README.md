# App Store Screenshots

Professional marketing screenshots for the 6.7" iPhone display (1290×2796).

| File | Feature |
|------|---------|
| `01-team-chat.png` | Live Team Chat |
| `02-ai-assistant.png` | AI Reply Assistant |
| `03-voice-messages.png` | Voice Messages |
| `04-photo-location.png` | Photo & Location Sharing |
| `05-live-support.png` | Live Support & Push Notifications |

Regenerate:

```bash
python3 scripts/appstore-connect/generate_screenshots.py
```

Upload to App Store Connect:

```bash
python3 scripts/appstore-connect/upload_app_store_screenshots.py
```
